# Cybersecurity Learning Path

Benvenuto nel mio percorso completo di studio e pratica della Cyber Security.  
Questa repository contiene laboratori, progetti e attività pratiche organizzate in 18 settimane, dal livello base fino a competenze intermedie in Linux, Networking, Cloud Security e Offensive Security.

---

## Struttura della Repository
 
- **01-linux-security** – Laboratori e esercizi su Linux, utenti, permessi, servizi e hardening  
- **02-networking** – Configurazioni e analisi reti, protocolli, subnetting e VPN  
- **03-network-security** – Sicurezza di rete, firewall, IDS/IPS, monitoraggio traffico  
- **04-cloud-security** – Architetture cloud sicure, IAM, VPC, logging, compliance  
- **05-devsecops** – Integrazione sicurezza nei processi DevOps, container security  
- **06-offensive-security** – Laboratori controllati di pen-testing e analisi vulnerabilità  
- **templates** – Template per checklist giornaliere da duplicare durante le settimane

## Come usare questa repository

1. Ogni settimana contiene un **README con obiettivi, attività e tool usati**
2. All’interno delle settimane ci sono cartelle:
   - `screenshots/` → prove visive
   - `configs/` → file di configurazione reali
   - `reports/` → output di scansioni, analisi, lab
   - `notes/` → appunti giornalieri e checklist
